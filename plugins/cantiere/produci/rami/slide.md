# Ramo Slide

Parte di /produci.

1. Crea il deck: un artifact di tipo Slides se disponibile, altrimenti un file `.pptx` con la skill `pptx`. La scaletta viene dalla "Struttura del prodotto": una slide = un messaggio.
2. Costruisci una slide alla volta, con le regole "Fonti" di SKILL.md, scrivendo anche le note del relatore. Appena una slide è finita e verificata, spuntala in `docs/cantiere/avanzamento.md` con la data.

Il ramo è finito quando tutte le slide sono spuntate. Poi vai al passo 3 di SKILL.md (humanizer), sul testo delle slide e sulle note del relatore.
