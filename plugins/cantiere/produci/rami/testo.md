# Ramo Testo

Parte di /produci.

1. Crea un documento modificabile: Docs (skill `docs`) se disponibile, altrimenti un file Markdown nella cartella del progetto. La scaletta viene dalla "Struttura del prodotto".
2. Scrivi una sezione alla volta, con le regole "Fonti" di SKILL.md. Appena una sezione è finita e verificata, spuntala in `docs/cantiere/avanzamento.md` con la data.

Il ramo è finito quando tutte le sezioni sono spuntate. Poi vai al passo 3 di SKILL.md (humanizer).
